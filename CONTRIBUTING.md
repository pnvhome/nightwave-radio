# Contributing

Please use English for issues, pull requests, documentation and interface text.

Run `swift test` before submitting changes. For changes to generation or packaging, include the relevant real-model or bundle-audit result and your Mac chip/macOS version. Do not commit recordings, downloaded weights, logs, credentials, or personal paths.

Keep instrumental score validation and the native adapter enabled. Do not replace this pipeline with a negative-vocal prompt. Preserve existing models, recordings and user settings.

Report reproduction steps and the app version. Review logs before attaching them: they may contain prompts and local paths. Changes to third-party dependencies must retain their licenses and update `THIRD_PARTY_NOTICES.md`.
